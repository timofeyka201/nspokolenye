# Поколение: сервис малой группы

Сервис для малой группы проекта «Поколение». Он работает в трёх видах, и у всех одна общая база:

1. **Сайт.** Открывается в браузере, вход через Telegram, паролей нет.
2. **Mini App.** То же приложение, только внутри Telegram.
3. **Бот.** Регистрация, напоминания, анонимные вопросы, оценка встреч. В чате группы бот считает активность.

## Что умеет

| Раздел | Возможности |
|---|---|
| **Главная** | Ближайшая встреча с кнопкой «Отметиться», быстрые действия, активность за месяц, опросы и задания, Random Coffee, объявления, топ-5, дни рождения |
| **Календарь** | Месяц и список; встречи, эфиры, дедлайны и задания; подписка для Google и Apple Calendar; кнопка «Добавить в календарь» у каждого события |
| **Встречи** | Отметка по QR-коду или по 4-значному коду; ручная отметка посещаемости командой; после встречи бот просит поставить оценку звёздами (анонимно) |
| **Цели** | Цели с шагами и сроками, отметки «что сделано», история; наставник видит общую картину по всей группе |
| **Люди** | Профили (имя, ДР, ник, интересы, о себе, «могу помочь / ищу помощь», цели, активность в группе и в чате), подбор «кто поможет», «Спасибо» |
| **Анонимные вопросы** | Наставнику или любому участнику, через приложение или бота (`/ask`); получатель отвечает, автор получает ответ, но остаётся анонимным |
| **Материалы** | Папки и ссылки, поиск |
| **Задания** | Наставник публикует, участники сдают с комментарием; напоминание за сутки до срока |
| **Опросы** | Шаблоны «Время» и «Тема», можно выбрать несколько вариантов, анонимно, автозавершение; голосовать можно кнопками прямо в чате |
| **Random Coffee** | Каждый понедельник в 10:00 случайные пары (недавние повторяются как можно реже); в пятницу бот спрашивает «Встретились?» |
| **Рейтинг** | Баллы за активность, топ-5 виден всем, своё место видит каждый, полный список видят наставник, ментор и куратор; 12 достижений; «Лидер месяца» |
| **Объявления** | С закреплением; участники получают их в личку, по желанию дублируются в чат |
| **Бот в чате** | Считает сообщения (только количество, тексты не сохраняет), напоминает о встречах за сутки и за час, приветствует новичков, поздравляет с ДР, подводит итоги месяца; команды `/next`, `/schedule`, `/top`, `/poll` |
| **Уведомления** | Можно выключить каждый вид отдельно, есть «тихие часы» |

**Роли.** Роли такие: участник, ментор, наставник и куратор. У ментора, наставника и куратора одинаковые управленческие права: встречи, задания, материалы, объявления, заявки, обратная связь. Роли назначает только куратор. Главные администраторы указываются в настройках сервера: они видят все группы и могут создавать новые.

**Анонимность.** У отзывов и вопросов в базе не хранится автор, хранится только зашифрованный отпечаток. По нему нельзя узнать человека. Зато по нему можно запретить оставить два отзыва на одну встречу, доставить автору ответ и заблокировать спамера, не узнав, кто это. Комментарии к отзывам показываются в случайном порядке и без времени. За анонимные действия баллы не начисляются, иначе по начислению баллов можно было бы вычислить автора.

## Как два проекта живут на одном сервере

```
                        ┌──────────── Caddy (порты 80/443, HTTPS) ────────────┐
 uborka.ru  ──────────► │ /etc/caddy/Caddyfile           → localhost:3000     │ → «Порядок»  (/opt/poryadok,   база /var/lib/poryadok)
 app.домен.ru ────────► │ /etc/caddy/sites/pokolenie.caddy → localhost:3100   │ → «Поколение» (/opt/pokolenie, база /var/lib/pokolenie)
                        └─────────────────────────────────────────────────────┘
```

- У каждого проекта своя папка с кодом, своя база, своя системная служба и свой порт. Они не видят друг друга.
- **Caddy** — это «вахтёр» на входе. Он смотрит, на какой домен пришёл запрос, и отправляет его нужному проекту. Он же сам получает и продлевает HTTPS-сертификаты.
- Скрипт «Поколения» не трогает настройки «Порядка». Он кладёт свой сайт в отдельный файл и добавляет в общий Caddyfile одну строку подключения. Если «Порядок» при обновлении перезапишет Caddyfile, «Поколение» в течение минуты вернёт эту строку само.
- На сервере с 1 ГБ памяти скрипт создаёт файл подкачки на 1 ГБ (если его ещё нет) и ограничивает память «Поколения» до 350 МБ, чтобы проекты не мешали друг другу.

## Установка на сервер

### 1. Создать бота

1. В Telegram откройте [@BotFather](https://t.me/BotFather), отправьте `/newbot`, придумайте имя и юзернейм. Сохраните **токен**: строку вида `123456:ABC-DEF...`.
2. `/setprivacy` → выберите бота → **Disable**. Без этого бот не будет видеть сообщения в чате и не сможет считать активность.
3. После установки на сервер (шаг 4) включите **Main Mini App**: `/mybots` → бот → **Bot Settings** → **Configure Mini App** → **Enable Mini App** → укажите адрес сайта (`https://app.ваш-домен.ru`). После этого ссылки вида `t.me/бот?startapp` будут сразу открывать приложение.

### 2. Узнать свой Telegram ID

Напишите [@userinfobot](https://t.me/userinfobot) и запишите число из ответа (Id). Это сделает вас главным администратором.

### 3. Домен

У регистратора домена добавьте **A-запись**: имя `app` (или любое другое), значение — IP вашего сервера. Через 5–30 минут адрес `app.ваш-домен.ru` начнёт вести на сервер. Пока домена нет, сайт работает по техническому адресу вида `https://pokolenie.1-2-3-4.sslip.io`, где цифры — это IP сервера.

### 4. Установить

Подключитесь к серверу (`ssh root@IP`) и выполните по очереди:

```bash
mkdir -p /etc/pokolenie && nano /etc/pokolenie/env
```

Впишите в файл (подставьте свои значения), сохраните: Ctrl+O, Enter, Ctrl+X.

```
BOT_TOKEN=123456:ABC-DEF...
ADMIN_TG_IDS=123456789
DOMAIN=app.ваш-домен.ru
```

Затем запустите установку:

```bash
curl -fsSL https://raw.githubusercontent.com/timofeyka201/pokolenie/main/deploy/bootstrap.sh | bash
```

Скрипт сам установит всё нужное, настроит службы и HTTPS и в конце выведет адрес сайта. Если репозиторий приватный, скрипт покажет ключ: его нужно добавить в GitHub → репозиторий → Settings → Deploy keys.

### 5. Подключить чат группы

1. Откройте приложение (кнопка «Открыть» в боте) и заполните профиль.
2. **Ещё → Управление группой → Чат группы → Получить код**.
3. Добавьте бота в чат группы, сделайте его администратором и отправьте в чат `/setup КОД`.
4. Ссылку-приглашение из «Управление группой → Приглашение» отправьте ребятам. Кто уже состоит в чате, попадёт в группу сразу, остальные — после одобрения командой.

Есть и быстрый путь для главного администратора: добавить бота в чат и отправить `/setup` без кода. Группа создастся сама, а вы станете в ней куратором.

### Обновления

Сервер раз в минуту проверяет ветку `main` на GitHub. Если там новый код, он сам обновляется и перезапускается. Чтобы выложить новую версию, достаточно сделать `git push`. База при обновлениях не затрагивается.

### Полезные команды

```bash
journalctl -u pokolenie -f              # логи приложения и бота
journalctl -u pokolenie-update -n 30    # история автообновлений
systemctl restart pokolenie             # перезапуск
nano /etc/pokolenie/env && bash /opt/pokolenie/deploy/install.sh   # изменить настройки (домен, токен)
cp /var/lib/pokolenie/pokolenie.db ~/backup-$(date +%F).db          # резервная копия базы
```

> Файл `/var/lib/pokolenie/secret.key` нужен для анонимности. Сохраняйте его в резервной копии вместе с базой. Если его потерять, авторы не смогут увидеть свои старые анонимные вопросы.

## Запустить на своём компьютере

Нужен Node.js 22.13 или новее.

```bash
npm install
npm run dev     # http://localhost:3100 — на экране входа появится «Тестовый вход» без Telegram
```

Чтобы бот работал локально, задайте `BOT_TOKEN=...` (лучше отдельного тестового бота). Mini App внутри Telegram требует HTTPS, поэтому полностью его проверить можно только на сервере.

## Устройство

- `server/`: Node.js + Express. База SQLite встроена в Node 22, отдельная база данных не нужна.
  - `api/`: запросы приложения (`group.js` — главная, люди, управление; `events.js` — календарь, отметки, отзывы; `goals.js`; `content.js` — материалы, задания, объявления, опросы; `social.js` — вопросы, Random Coffee, «спасибо», рейтинг).
  - `bot.js`: Telegram-бот (grammY). `jobs.js`: фоновые задачи (напоминания, оценки встреч, Random Coffee, дни рождения, итоги месяца). `notify.js`: очередь сообщений с тихими часами. `points.js`: баллы, уровни, достижения. `anon.js`: анонимность. `ical.js`: календарь.
- `public/`: интерфейс без сборки на Preact + htm (ES-модули), экраны лежат в `js/views/`. Шрифты Unbounded (логотип) и Inter лежат локально.
- `deploy/`: установка и автообновление на сервере.
